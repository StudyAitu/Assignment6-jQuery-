## Project Overview

This project demonstrates the practical application of jQuery
for manipulating HTML elements, creating interactive effects,
handling user events, and building animations.

The website consists of five interconnected pages with
a responsive navigation bar and a consistent visual design.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- jQuery 3.7.1
- Git and GitHub
- GitHub Pages

## Project Pages

### 1. Setup & Selectors — index.html

Task 0:
- Import jQuery using a CDN.
- Initialize $(document).ready().
- Print "jQuery is ready!" in the browser console.

Task 1:
- Select HTML elements by ID, class, and tag.
- Modify text using .text().
- Insert HTML using .html().
- Change CSS properties using .css().

### 2. Effects — effects.html

Task 2:
- Hide elements using .hide().
- Show elements using .show().
- Toggle visibility using .toggle().

Task 3:
- Fade images using .fadeIn().
- Hide images using .fadeOut().
- Toggle fading using .fadeToggle().

Task 4:
- Collapse content using .slideUp().
- Expand content using .slideDown().
- Toggle content using .slideToggle().

### 3. DOM Manipulation — dom.html

Task 5:
- Add items using .append() and .prepend().
- Remove items using .remove().

Task 6:
- Modify image src attributes.
- Modify hyperlink href attributes.

Task 7:
- Read user input using .val().
- Display live input using .text().

### 4. Animations — animations.html

Task 8:
- Increase square size and change its position.

Task 9:
- Create a sequence of four animations.

Task 10:
- Combine movement, resizing, and opacity changes.

### 5. Mini Project — gallery.html

Task 11:
- Interactive Image Gallery.
- Filter images by category.
- Display enlarged image previews.
- Use fading and resizing animations.
- Navigate using Previous and Next buttons.
- Support keyboard navigation.

## How to Run

1. Clone or download the repository.
2. Open the project folder.
3. Open index.html in a modern web browser.
4. Make sure the internet connection is available.
5. Navigate through the website using the navbar.
6. Test each interactive element.

## Deployment

The project is designed for GitHub Pages.

To deploy:
1. Push all project files to GitHub.
2. Open repository Settings.
3. Select Pages.
4. Choose Deploy from a branch.
5. Select main and / (root).
6. Save and wait for deployment.
